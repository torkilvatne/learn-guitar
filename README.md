# Absolutely Understanding Guitar

Client-side music-theory support site (React + Vite + TypeScript + Tailwind CSS v4). See `PROJECT_DESCRIPTION.md` for scope and `TASKS.md` for the build plan.

```
npm run dev       # start dev server
npm run build     # type-check + production build
npm run test      # run unit tests
npm run lint      # lint
npm run format    # format with Prettier
```
